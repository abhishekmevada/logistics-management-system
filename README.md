# Logistics Management System

A MERN-based Logistics Management System for managing shipments,
drivers, vehicles, warehouses, trips, deliveries and related
logistics operations.

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT

## Phase 1

- Project Setup
- Authentication
- User & Role Management
- Role-Based Dashboard

## User Roles

- Admin
- Logistics Manager
- Dispatcher
- Warehouse Manager
- Driver
- Customer
